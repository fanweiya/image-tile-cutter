## 📖 项目简介

在计算机视觉检测、生物显微图像分析、航天遥感地图处理以及网页瓦片切分场景中，经常面临数千甚至数万像素级的超大图像，直接送入卷积网络或大模型容易引发显存溢出（OOM），或由于大幅缩放导致关键微小目标特征丢失。

**ImageTileCutter** 是一款基于 Go 与高性能 MyGo 现代化轻量 GUI 框架构建的专业大图切块与交互裁剪工具。提供纯客户端图形界面、实时交互式选区框选、并发切片流水线、掩码成对切分、智能背景/低信息过滤以及基于元数据清单的反向无损拼接全生命周期能力。

## ✨ 核心特性

### 1. 批量智能切片 (Batch Slicing)
- **滑动窗口切分 (Sliding Window)**:
  - 自由设定切片目标宽度与高度（如 512×512、1024×1024）。
  - **支持像素 (px) 与百分比 (%) 双重步长单位**：步长重叠既可按固定像素设定，也可按切片尺寸百分比（如 10%、20%、50%）换算，大幅提升设置灵活性。
  - **数值步进微调控制**：提供切片长宽与重叠步长的 `[－]` 与 `[＋]` 步进调节，步长粒度可自由设定（1 / 8 / 16 / 32 / 64 / 128 px），兼顾精确微调与快速增减。
  - 支持配置横向与纵向重叠步长（Overlap X / Y），有效解决目标物体落在切分缝隙处导致无法检测的问题。
- **等分网格切分 (Grid Split)**:
  - 自定义分割行数与列数（如 4×4、8×8），快速将大图均分为矩阵切片。
- **4 种专业边缘处理策略**:
  - `回溯对齐 (保持尺寸)`：边缘余量不足切片大小时，切框自动向原图内回溯对齐，确保所有输出切片尺寸严格一致且无黑边填充。
  - `填充补全 (固定尺寸)`：边缘余量不足时，以纯色背景进行边缘填充，输出绝对固定分辨率。
  - `丢弃边缘 (忽略余量)`：放弃未满足完整切片宽高的边缘碎块。
  - `保留实际 (不规则尺寸)`：直接裁切剩余像素区域，切片实际尺寸与余量相同。

### 2. 智能内容质量过滤与直观红叉标示 (Smart Filtering & Visual Red X)
- **智能过滤纯单色/背景切片**：
  - 自动统计切片中背景与单色比例，当超过设定阈值（如 95%）时自动过滤舍弃，避免数据集产生大量纯黑、纯白无效负样本。
- **智能过滤低方差平坦切片**：
  - 快速计算切片灰度像素方差，自动剔除无纹理特征的模糊平坦切片。
- **预览直观红框与红色大叉 (X) 标示**：
  - 开启网格预览时，被算法判定为过滤废弃的切片以**半透明红色填充、红色边框与红色对角交叉线 X** 醒目标注；保留的有效切片保持清晰的青色边框，切片质量一目了然。

### 3. 多尺度与多分辨率金字塔切片 (Hierarchical Multi-Scale Tiling)
- **金字塔分级并发切分**：
  - 勾选支持 `100% (原始超微细节)`、`50% (中景半分辨率)` 与 `25% (宏观全景)` 等多尺度输出。
  - 在输出文件夹下自动按 `scale_1.0x/`、`scale_0.5x/`、`scale_0.25x/` 构建清晰的分级目录树，利于多尺度目标检测与遥感/病理全域模型训练。
  - 元数据清单记录各个切片的 `scale` 尺度属性。

### 4. 任意多边形 / 自由套索 ROI 裁剪 (Polygon & Freehand Lasso ROI)
- **突破矩形选区限制**：针对培养皿圆形细胞组织、遥感不规则地块或数字病理活检边缘，提供任意多边形与套索圈定功能。
- **顶点交互采集与自动闭合**：直接在大图预览视口内点击标定顶点（>=3 点自动闭合），系统仅对覆盖或交叠多边形内部的目标切片进行精确裁切。

### 5. 高级质量度量与清晰度检测 (Advanced Quality Metrics & Heatmap)
- **智能单色/空白背景过滤**：自动统计背景占比，过滤纯黑/纯白无效切片。
- **低方差平坦纹理过滤**：计算灰度像素方差，自动剔除无纹理特征的平坦切片。
- **拉普拉斯聚焦模糊过滤 (Laplacian Blur Detection)**：
  - 针对显微扫描边缘虚焦模糊现象，通过 3×3 拉普拉斯卷积核方差精准识别聚焦清晰度，自动滤除离焦模糊废片。
- **大津阈值生物组织前景比 (Otsu Foreground Ratio)**：
  - 运用全局双峰大津算法将切片像素自动二值化，智能计算有效样本组织占比，剔除空白载玻片切块。
- **指标质量热力图覆盖 (Tile Metric Heatmap Overlay)**：
  - 支持在大图网格上开启热力图层，以蓝（低值）、青、绿、黄、红（高值）动态色谱渲染各切片的方差、清晰度或组织比分布。
- **直观红框与红色大叉 (X) 判定标示**：
  - 被任何质量规则过滤或手动排除的切片，在预览图中均以半透明红底、红色边框与对角红叉 X 醒目标注。

### 6. 视图交互与检查复核体验 (Inspection & User Experience)
- **鼠标悬停浮窗即时诊断 (Tile Hover Tooltip)**：
  - 鼠标移动至网格上方时，实时悬浮诊断该切片的行列号、绝对像素范围、均值亮度、方差、拉普拉斯清晰度、组织占比及剔除原因。
- **鹰眼鸟瞰小地图导航器 (Mini-map Navigator)**：
  - 在预览视口右下角提供整图缩略图与当前视野黄色视口框，在 100% 原始分辨率超微漫游时实时感知全局方位。
- **切片结果画廊抽检 (Tile Gallery Previewer)**：
  - 内置独立抽检画廊标签页，切图完毕后直接在软件内瀑布流复核全部产出切片，支持放大查验与一键删除废片。
- **深度超大图浏览与连续缩放**：
  - 支持 `自适应窗口`、`5%` 至 `200%` 连续缩放，搭配双向平滑滚动与键盘导航。

### 7. 离散切片无损反向拼接 (Reconstruction / Stitching)
- 切图过程中自动生成规范的 `manifest.json` 元数据清单，包含原图分辨率、切片行列索引、全局绝对包围盒坐标 `[x, y, w, h]`。
- 提供反向拼合引擎，选择清单文件后一键无损重构并拼回超高分辨率全景原始大图。

### 6. 超大图 (Gigapixel / 亿级像素) 深度优化
- **毫秒级头部元数据解析**：采用 `image.DecodeConfig`，在不到 1 毫秒内瞬间获取超大图像尺寸，界面立即响应。
- **后台异步解码流水线**：大图解码在独立后台 Goroutine 执行，搭配原子序列号自动过滤过期请求，主界面 60 FPS 永不卡顿。
- **金字塔预览缓存代理**：自动构建 2048 像素代理缓存，视口实时缩放重采样耗时 `< 2ms`，支持在数万像素级巨幅图像上流畅实时拖拽框选。
- **默认自适应窗口**：载入任何分辨率大图均自动计算最佳贴合比例，免去手动调整烦恼。
- **内存封顶与多核切片并发**：批量切图阶段单图顺序解码进内存，切片多核并发写盘，彻底根治多路大图并发引发的内存爆炸崩溃。

### 7. 多镜像无感在线更新 (Resilient Auto Updates)
- 集成现代化客户端热更新架构与签名校验机制。
- 内置多组 GitHub 镜像加速通道（`ghfast.top`、`gh-proxy.com`、`ghproxy.net`、`ghproxy.cfd` 等），国内网络环境亦可顺畅更新。
- 系统托盘菜单常驻，支持随时点击「检查更新...」。

## 🛠 本地源码构建

### 环境要求
- **Go**: 1.22 或更高版本
- **Windows OS**: 64-bit
- **MyGo CLI** (可选但推荐): `go install github.com/egoist/mygo@latest`
- **rsrc** (用于嵌入 Windows 图标): `go install github.com/akavel/rsrc@latest`

### 构建步骤
1. 克隆代码仓库：
   ```bash
   git clone https://github.com/fanweiya/image-tile-cutter.git
   cd image-tile-cutter
   ```

2. 安装依赖：
   ```bash
   go mod download
   ```

3. 一键编译打包：
   - 使用附带的自动化构建脚本：
     ```cmd
     .\build.bat
     ```
   - 或使用原生 Go 命令编译无控制台黑框版本：
     ```bash
     rsrc -ico icon.ico -o rsrc.syso
     go build -ldflags "-s -w -H windowsgui" -o ImageTileCutter.exe .
     ```
